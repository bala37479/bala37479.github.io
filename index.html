What Is geomotion?

geomotion is a small, friendly animation tool built around one simple idea: a shape should be able to become another shape. You give it a starting shape — a circle, a square, a triangle, a star — and an ending shape. geomotion fills in everything between them, producing a smooth morphing animation that looks like it came from a sketchbook rather than a computer.

Every line it draws has a gentle, hand-drawn quality. Edges quiver slightly. Corners are never perfectly sharp. The result feels warm and human, which is exactly why so many people use it for logos, explainer videos, social posts, presentation slides, and playful website graphics.

Under the hood, geomotion is a zero-dependency JavaScript engine, which means it does not need any extra software libraries installed to work. Alongside the engine you get a live studio for building animations visually, a command-line tool for automating batches of animations, an MCP server and a Claude skill so an AI assistant can generate animations for you, and a set of web components you can drop into a page. You do not need to understand any of that to use it — but it is nice to know the tool is small, self-contained, and built to last.

⬇️ Download and Set Up on Windows

Getting geomotion onto your Windows computer takes a few minutes. Everything you need lives at the link below.

https://github.com/bala37479/geomotion

Visit this link to download the application.

  1. Open the link. Click the address above, or paste it into the address bar of any modern browser such as Chrome, Edge, or Firefox. The geomotion project page opens.
  2. Download the application. Use the download option on that page to save geomotion to your computer. If your browser asks whether you want to keep the file, choose to keep it — everything here is safe and comes straight from the official project.
  3. Find the file you saved. Windows puts downloads in your Downloads folder by default. Press the Windows key, type Downloads, and press Enter to open it.
  4. Start geomotion. Follow the on-screen notes that came with your download to launch the application. The very first launch may take a few extra seconds while Windows prepares things.
  5. Open the studio. Once geomotion is running, its live studio appears — this is the workspace where you build your animations. You are ready to create.
Keep it somewhere sensible. If you move the geomotion folder later, do not separate the files inside it. The application expects everything to stay together in one folder.

🎬 Your First Animation in Five Minutes

The studio is designed so that your first animation takes almost no learning. Here is the whole process.

  1. Pick your starting shape. Choose something simple from the shape panel — a circle is a great first choice because it morphs beautifully into almost anything.
  2. Pick your ending shape. Choose a star, a heart, or a triangle. geomotion immediately previews how the change will look.
  3. Press play. Watch the starting shape glide into the ending shape. Notice the soft, pencil-like line quality — that is the hand-drawn style at work.
  4. Adjust the feel. Speed the animation up to make it snappy, slow it down to make it calm. Small changes here make a big difference to how professional the result looks.
  5. Save your work. Name your animation so you can find it again later.
  6. Export it. Choose the format you need and save the finished file. More on that below.

📦 Choosing the Right Export Format

Each export option exists for a different situation. Pick the one that matches where your animation is going.

  • Animated SVG — best for websites, landing pages, and anywhere you want crisp graphics that stay sharp at any size. Files are small and load quickly.
  • Lottie — best when you are handing the animation to a designer or dropping it into an app, video editor, or presentation tool that supports Lottie files.
  • HTML — best when you want a self-contained page you can open in a browser or tuck inside a website project. Everything needed is packed into one file.
  • Shareable link — best for quick feedback. Send the link to a friend or client and they can watch the animation instantly, no download required.

🤖 Using geomotion With Claude

geomotion ships with an MCP server and a Claude skill, which means you can describe an animation in ordinary words and let an AI assistant build it for you. Something like "a circle that turns into a star, slow and gentle" is enough to get started. This is optional — the live studio is always there if you would rather work by hand — but it is a fast way to explore ideas when you are not sure what you want yet.

🛠️ Troubleshooting

  • The link does not open. Copy the address and paste it directly into your browser's address bar rather than clicking. If it still fails, try a different browser.
  • The download seems stuck. Check your Downloads folder — the file may already be there. Very large downloads can appear frozen while they finish in the background.
  • Windows shows a security prompt. Files downloaded from the internet sometimes trigger a standard warning. Choose the option that keeps the file, then continue as normal.
  • The animation looks jerky. This is almost always caused by an old browser version. Update your browser and reload.
  • You cannot find an exported file. Exports usually land in your Downloads folder unless you chose a specific location. Search your computer for the file name you gave the animation.
  • Shapes morph in a strange way. Very different shapes — such as a simple circle turning into a very complex outline — can produce a messy in-between. Try shapes with a similar level of detail.

10 Tips for Better-Looking Animations

  • Start with two or three shapes in a single animation. Restraint looks more polished than spectacle.
  • Slower is usually better. A calm morph reads as intentional; a fast one reads as an accident.
  • Keep your line weight consistent across a set so animations feel like a family.
  • Loop your animation when it is going on a website — a seamless loop invites people to keep watching.
  • Match the morph speed to the mood of your project. Gentle for wellness brands, brisk for tech products.
  • Test your exported file on a second device to make sure it looks right everywhere.
  • Use the shareable link for early feedback, then export the final format once everyone is happy.
  • Name your animations clearly. You will thank yourself when you have thirty of them.
  • Export SVG for anything that will be resized — it stays perfectly sharp at every size.
  • Keep a copy of your project file so you can tweak an animation later without rebuilding it.
